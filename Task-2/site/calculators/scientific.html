History

    How to use

    1. Pick Degrees or Radians for trigonometry.
    2. Type an expression such as sin(30) + 2^3, or use the keys.
    3. Press = or Enter. Use Ans to reuse the last answer.

    Example

    sin(30) in degrees is 0.5. √(144) + 5! is 132. 2^10 is 1024.

    Helpful information

    Which functions are supported?

    sin, cos, tan, asin, acos, atan, ln, log (base 10), sqrt, cbrt, abs, exp, plus π, e, powers (^), factorial (!) and %.

    Is it safe?

    Yes. Expressions are read by a small built-in parser. Nothing you type is run as code.

    Why does tan(90) show an error?

    In degrees, tan(90) is undefined, so the calculator says so instead of showing a huge number.
